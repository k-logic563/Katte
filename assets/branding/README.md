# Katte Brand Assets

KatteのBrand markは、家族から届く依頼を表す「吹き出し」と、購入完了を表す
「チェック」を組み合わせる。

## Colors

- Muted Blue Green: `#3B9C8F`
- Deep Teal: `#155E57`
- Warm Off-white: `#F7FBFA`

## Files

- `app_icon.png`: 1024×1024、alphaなしのMaster App Icon
- `app_icon_foreground.png`: Android Adaptive Icon生成用の透過foreground
- `splash_icon.png`: Native Splash生成用の透過mark
- `katte_thumbnail.png`: 1200×630のPortfolio / SNS用Thumbnail

Launcher IconとSplashの生成設定はProject rootの `pubspec.yaml` で管理する。
