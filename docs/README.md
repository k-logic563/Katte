## Product Concept

> 家族の「買っといて」を、リアルタイムで共有。

「今スーパーにいるけど、何かいる？」  
「牛乳お願い」  
「それもう買ったよ」

こうした日常のやり取りを、Katte上でシンプルに完結させることを目指します。

## MVPの核

Katte のMVPでは、次の体験を最優先します。

1. 家族・グループで同じ買い物リストを共有できる
2. 誰かが商品を追加するとリアルタイムで反映される
3. 誰が追加したか分かる
4. 商品が追加されたらプッシュ通知される
5. 誰かが購入済みにすると全員へ即時反映される

## Non-goals

MVPでは以下を優先しません。

- 家計簿
- レシート管理
- 商品価格比較
- 店舗検索
- ECサイト連携
- AIによる商品提案
- 高度なカテゴリ分類

Katte は「高機能な買い物管理アプリ」ではなく、
**買ってきてほしいものを最短で共有するアプリ**として設計します。
