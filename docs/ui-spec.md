# Katte UI Specification

## 1. Design Principle

Katteは毎日の買い物で使うため、
操作説明がなくても分かるUIを目指す。

キーワード：

- Simple
- Friendly
- Fast
- Lightweight

機能を見せるより、
買い物リストそのものを主役にする。

---

# 2. Main Navigation

MVPではBottom Navigationを増やしすぎない。

基本：

```text
Shopping
Settings
```

グループ切り替えはShopping画面上部から行う。

---

# 3. Login

```text
Katte

家族の「買っといて」を、
リアルタイムで共有。

[ Googleで続ける ]
```

iOS / AndroidともにGoogleログインを表示する。
Apple Sign InはPhase 2.5またはリリース前対応とする。

---

# 4. First Group Setup

グループ未参加の場合：

```text
最初のグループを作ろう

グループ名
[ 岩田家 ]

[ グループを作成 ]
```

作成後、招待導線を表示する。

---

# 5. Shopping List

Katteのメイン画面。

```text
岩田家 ▼

康平が買い物中です

買ってきてほしいもの

○ 牛乳
  由美 ・ 2分前

○ 卵 ×2
  康平 ・ 10分前

○ ティッシュ
  由美 ・ 20分前


[ ＋ 買ってきてほしいもの ]

[ 🛒 買い物をはじめる ]
```

---

# 6. Add Item

可能な限り軽いUIにする。

Bottom Sheet例：

```text
買ってきてほしいもの

商品名
[ 牛乳 ]

個数
[ 1 ]

メモ
[ 任意 ]

[ 追加する ]
```

商品名以外は任意。

追加後は即座に閉じる。

---

# 7. Purchased

商品をタップまたはチェックする。

```text
✓ 牛乳
  由美 → 康平が購入
```

購入済みは現在リストの下部、
または履歴画面へ移動する。

MVPでは削除せず履歴として保持する。

---

# 8. Shopping Mode

未開始：

```text
[ 🛒 買い物をはじめる ]
```

開始後：

```text
🛒 買い物中

買い忘れがないか確認しよう

[ 買い物を終了 ]
```

他メンバー：

```text
🛒 康平が買い物中です

追加するものがあれば今のうちに！
```

この状態では商品追加ボタンを特に目立たせる。

---

# 9. Members

```text
岩田家

メンバー

康平
由美

[ ＋ メンバーを招待 ]
```

MVPの招待方法候補：

- 招待リンク
- QR Code

まずは招待リンクを優先する。

# 11. Empty State

商品なし：

```text
今日はまだ何もありません

買ってきてほしいものを
追加してみよう。

[ ＋ 追加する ]
```

---

# 12. Error UX

通信エラー：

```text
更新できませんでした

通信状態を確認して
もう一度お試しください。

[ 再試行 ]
```

ユーザーが入力した内容を可能な限り失わない。

---

# 13. Interaction Principles

## 商品追加

最重要。

1〜2タップで入力開始できる。

## 購入

誤操作を防ぎつつ速くする。

候補：

- Checkbox
- Swipe
- Tap

Phase 1で触って決定する。

## Delete

即時完全削除ではなく、
Undoを検討する。

---

# 14. Visual Direction

初期方向性：

- 明るい
- 白ベース
- 大きめの余白
- 丸みのあるUI
- 少しポップ
- 子どもっぽくしすぎない

ブランドカラーはUI実装時に決める。

Katteという名前から、
ショッピングカートをそのままロゴにする必要はない。

「お願いが届く」「家族で共有する」印象を重視する。
